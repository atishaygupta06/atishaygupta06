### 🚀 Featured Project

#### [Healthcare AI Revenue Intelligence](https://github.com/atishaygupta06/healthcare-ai-revenue-intelligence)

An end-to-end analytics and machine learning project designed to identify potential healthcare claim denials and highlight financial exposure using synthetic healthcare data.

**Project highlights:**
- Generated and analyzed 100,000 synthetic healthcare claims.
- Built and compared three machine learning classification algorithms.
- Developed a predictive model for identifying potentially denied claims.
- Achieved 83.82% accuracy on the held-out test dataset using Logistic Regression.
- Integrated Python, MySQL, and Power BI into an analytical workflow.
- Created a three-page interactive Power BI dashboard.

**Tech Stack:** Python | Pandas | Scikit-learn | MySQL | Power BI
